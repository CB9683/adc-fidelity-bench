# First Small CNN Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Train, save, reload and quantitatively evaluate a small direct ADC CNN against the two implemented conventional estimators, without patient data or leakage.

**Architecture:** Reuse the existing original-phantom, complex-noise and signal-derived reference functions. Keep observed-input preprocessing/model, grouped training data, and experiment orchestration separate. Fixed b=[0,1000] and four repetitions per b; no uncertainty or stopping claim.

**Tech Stack:** Python, project-local PyTorch, NumPy/SciPy, Matplotlib, pytest, JSON and provenance manifests. CPU is the reproducible first-run device; inspect MPS availability separately.

---

## Frozen first experiment

- New IDs `cnn-000` through `cnn-143`; seed 20261002; split 64 train / 16 validation / 32 reserved calibration / 32 final test geometries before deriving variants. Previously examined toy test IDs are excluded.
- Original 16×16, 0.5 mm phantoms, 2×2 signal averaging to 8×8 at 1 mm; synthetic ADC/S0 remain unchanged.
- SNR 5/20, focal radius 0.5/1.5 mm, signed contrast ±0.0003 mm²/s; circles only in training/validation. Ellipse is a prespecified unfamiliar final-test regime. Calibration remains unused.
- Train uses four noise draws per condition, validation two, test one; healthy and perturbed inputs both contribute to training. Independent paired noise during train/validation; both common/independent pairing in final evaluation.
- Fixed R=4 per b, eight total acquisitions. Two input channels: observed magnitude averages at each b, divided by the observed mean-b0 image's 95th percentile with floor 1e-6. No truth, ROI, generator sigma, paired reference, or unseen repetitions enters inference.
- CNN: Conv(2→16,3×3,pad1), ReLU, Conv(16→16,3×3,pad1), ReLU, Conv(16→1,1×1), softplus; output scaled by 1e-3 mm²/s. 2,641 parameters, 5×5 receptive field, no pooling or smoothness/perceptual loss.
- Tissue-masked MSE on ADC scaled by 1e3; mask is training loss support only. Average per-image tissue MSE so each generated example has equal weight.
- Adam lr=0.001, batch64, maximum80 epochs, CPU, two threads, seeds [11,22,33]. Save best validation-loss checkpoint for each seed; no final test result selects checkpoint or hyperparameters. Record all epoch losses. Replicates are optimization sensitivity, not independent anatomical groups.
- Final comparison: unchanged averaging and known-sigma Rician MLE plus each frozen CNN checkpoint on identical acquisitions. Report ADC bias/MAE/RMSE, invalid/focal-failure counts, signed focal recovery/change error and nonfocal/spillover error. Aggregate noise within anatomy/condition then anatomy equally; compact tables average conditions within anatomy before averaging anatomies. Ratios remain signed and subset counts explicit.
- A finite CNN output is not evidence of identification or calibrated confidence. No clinical, scanner-time, coverage or stopping claim. No architecture/loss changes after final test inspection.
